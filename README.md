## 数独アプリ (sudoku)

### 概要
JavaFXを用いた9×9の数独(ナンプレ)GUIアプリ
問題ファイル(テキストファイル)から盤面を読み込み、ユーザがコンボボックスで数字を選択して解く方式

### 機能
- 問題ファイル(input.txt)から盤面を読み込み、9×9の盤面を表示
- 空きマスはコンボボックスで数字を選択して入力(固定マスは選択不可)
- 各マスのコンボボックスには、同じ行・列・3×3ブロック内にすでに存在する数字を除外した選択肢を表示
- 全マスが正しく埋まった場合にゲームクリアメッセージを表示
- リセットボタンで全ての空きマスを初期状態に戻す

## 四則演算電卓 (calculator)

### 概要
JavaFXを用いたGUI電卓アプリ
実数の四則演算を行い、計算結果を小数点以下最大6桁で表示

### 機能
- 四則演算(+, -, *, /)に対応
- 計算結果を小数点以下最大6桁で表示(整数入力も実数として計算)
- CE / C ボタン: 入力中の数式をクリア
- BS ボタン: 入力中の文字列を1文字削除
- ± ボタン: 数式先頭の符号を反転
- ゼロ除算時は「Error」を表示し、CE / C ボタンのみ受け付ける状態になる
